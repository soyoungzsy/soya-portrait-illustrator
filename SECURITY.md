# Security policy

## Supported version

Security fixes are applied to the latest tagged release.

## Reporting a vulnerability

Use GitHub’s private vulnerability reporting for this repository when available. Do not publish personal photos, private image URLs, provider credentials, or a working exploit in a public issue.

Include:

- A concise description of the behavior.
- The affected file and version.
- Minimal reproduction steps using synthetic images only.
- The expected security boundary.

This project treats writes outside the user-selected output directory, disclosure of source-image paths, credential exposure, and unintended publication of identifiable likenesses as security issues.
