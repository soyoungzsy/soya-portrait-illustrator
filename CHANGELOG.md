# Changelog

## 0.3.0 — 2026-10-09

- Separate the public complete-asset-pack default from personalized local Skill defaults.
- Validate preset identifiers and categories as safe path segments.
- Enforce that generated files remain inside the selected output directory.
- Normalize low-alpha cutout halos during export.
- Compose the 4:3 presentation preset from the transparent cutout instead of cropping the 16:9 master.
- Add repeatable exporter, transparency, dimension, and path-safety tests.
- Add GitHub Actions validation and a security-reporting policy.
- Record a privacy-preserving end-to-end validation summary.
- Replace the ambiguous chibi mode with a user-defined bean-eye anime mode and add realistic full-body proportion rules.
- Add an approved reusable pose library and an approximately 80% identity plus light-beautification boundary.
- Define the anime silhouette as cute, modest, and non-sexualized, without exaggerated feminine curves.

## 0.2.0 — 2026-10-09

- Expand from one portrait to four masters and 17 reusable export presets.
- Add the deterministic asset-pack exporter, contact sheet, and manifest.
- Document avatar, wallpaper, social, presentation, and future-layout use cases.

## 0.1.0 — 2026-10-09
