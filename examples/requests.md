# Example requests

These examples show how users can invoke the skill after attaching a photo.

## Complete asset pack

```text
用 $soya-portrait-illustrator 把这张照片做成一整套写实手绘素材。保留脸型、眼神、发型、眼镜、衣服配色和姿态，输出头像、三种手机屏保、朋友圈、小红书、PPT、透明人物、贴纸和左右留白版式。
```

```text
Use $soya-portrait-illustrator to create a complete bean-eye anime asset pack from this photo. Use small black bean eyes, a minimal nose and mouth, black hand-drawn outlines, colored-pencil fill, and flat 2D comic treatment. Keep the person recognizable and export all presets.
```

```text
用 $soya-portrait-illustrator 同时做写实手绘和豆豆眼动漫两套素材包。两套都保持相同人物、服装和配色，并使用相同的文件结构，方便对比。
```

## Realistic hand-drawn

```text
Use $soya-portrait-illustrator to turn this photo into a realistic colored-pencil and light-watercolor portrait. Keep my expression, hairstyle, glasses, clothing, crop, and background composition unchanged.
```

```text
把这张照片做成尽可能像本人的写实手绘头像。保留眼神和发型，把复杂背景简化成浅色纸面，但不要改变人物轮廓。
```

## Bean-eye anime

```text
Use $soya-portrait-illustrator to make a bean-eye anime version of this photo. Use small solid-black bean eyes, a minimal nose and mouth, black hand-drawn outlines, and colored-pencil fill. Keep the real hairstyle, smile, clothing colors, and identity. Use a transparent background.
```

```text
把照片里的人画成豆豆眼动漫风格，使用小黑豆眼、极简鼻嘴、黑色手绘线和彩铅填色；保留发型、表情、衣服配色和动作，不要大眼半写实或通用动漫脸。
```

## Two-style comparison

```text
Use $soya-portrait-illustrator to make two separate versions of this photo: one realistic hand-drawn portrait and one bean-eye anime portrait. Keep the same crop and background in both so I can compare the styles.
```

## One specific layout

```text
用 $soya-portrait-illustrator 只生成一张 16:9 写实手绘 PPT 封面。人物放右侧，左侧保留至少一半干净空间，不加文字。
```

```text
Use $soya-portrait-illustrator to make only a 1290×2796 realistic phone wallpaper. Keep the top clock area quiet and preserve the original expression and clothing.
```
