# Entry preparation · v0.4.1

## Reviewable positioning

An agent Skill that turns one approved character into a reusable personal IP library. First scenario: prepare a sharing session with an avatar, an editable title cover and a transparent PPT illustration; reuse the same approved identity for the next theme.

New in 0.4.0: local confirmed versions, saved palette, explicit reuse, narrow revisions with unchanged master bytes preserved, editable cover text, purpose-specific preview, mechanical checks and a reproducible installable ZIP. Four masters, 17 exports, two styles and master approval were already present in 0.3.0.

## Prepared in this repository

- Installable Skill source, short startup instruction, host capability precheck and README.
- Local version and delivery manifests; offline Python/Pillow helpers; regression tests.
- Original geometric synthetic fixture and fictional titles; no real photograph or likeness.
- Deterministic ZIP builder, privacy/history scan, MIT license and dependency attribution; optional CI template (online activation needs workflow permission).
- Known limits and honest separation of offline checks from image generation acceptance.

2. A real author-run acceptance session: selected authorized photo, one short instruction, approved masters, three actual deliverables, next-theme reuse and one narrow correction. Select provider, upload scope and cost with the author before any charge or upload.
3. A continuous recording: installation/enabling → host capabilities → photo upload → “按这张照片建立我的个人IP素材库” → necessary follow-up → master confirmation → actual delivery and preview → new-theme reuse. The current synthetic preview is not a substitute for this recording.
4. Author-approved self-use narrative and exact public permissions for source photo, generated likeness and feedback. Raw photo publication is optional; do not infer it from permission to process the photo.
